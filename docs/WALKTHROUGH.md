# Разбор двух примеров

Два входа, два вердикта. Один показывает, как движок пропускает сборку с оговоркой. Второй — как останавливает её.

Запуск:

```bash
python -m engine.run_all < examples/esports-240hz/build.json
python -m engine.run_all < examples/xeon-rtx4090-trap/build.json
```

---

## 1. Киберспорт 1080p / 240Hz

**Запрос:** CS2 и Valorant, 1080p, стабильные 240+ FPS, бюджет до 120 000 ₽.

| Компонент | Модель |
|---|---|
| CPU | Ryzen 7 7800X3D, 120W TDP |
| GPU | Radeon RX 7600 8GB, 165W TGP, PCIe 4.0 ×8 |
| MB | B650E, VRM `sweet_spot_stable` |
| RAM | 32 GB DDR5 |
| PSU | 650W |
| Cooler | башня 155 мм |
| Case | до 350 мм GPU, до 165 мм кулера |

### Что сказал движок

```text
STRUCTURAL
  GPU clearance:    110 мм
  Cooler clearance:  10 мм
  RAM gap:            9 мм
  → PASS

THERMAL
  CPU: 57.0 °C
  GPU: 30.6 °C
  Thermal soak: не активен
  → PASS

POWER
  Gaming load: 258 W
  Full load:   335 W
  Headroom:    1.94×
  → PASS

PROFILE
  RX 7600 → mainstream_efficiency_tgp_150w
  optimal для esports_1080p_240hz
  → PASS

CPU VRM
  CPU 120W требует sweet_spot_stable
  B650E имеет sweet_spot_stable
  → PASS

MVS
  Средний тир, нарушений 0
  → PASS
```

Итог:

```json
{
  "validation_status": "PASS_WITH_WARNINGS",
  "failed_check_ids": [],
  "warnings": [
    "Effective PCIe bandwidth 15.8 GB/s (Gen4 ×8) ниже рекомендованного 20.0 GB/s для 1440p+."
  ]
}
```

### Почему не чистый PASS

RX 7600 физически имеет только 8 линий PCIe 4.0. Для киберспорта 1080p это нормально: карта не упирается в шину. Но правило `l5_validation` консервативно проверяет bandwidth для игровых интентов и выдаёт предупреждение.

Движок не «подкручивает» результат под красивый PASS. Предупреждение остаётся, а решение `proceed_to_document` принимает инженер.

## 2. Ловушка с маркетплейса: Xeon + RTX 4090

**Запрос:** «Игровой монстр 4K», бюджет 120 000 ₽.

| Компонент | Проблема |
|---|---|
| GPU | RTX 4090, 348 мм, 3.5 слота, 320W |
| Case | максимум 300 мм GPU, 160 мм кулера |
| Cooler | 160 мм при лимите 155 мм с зазором |
| PSU | 450W, ATX 2.4 |
| MB | X99, 1 × M.2, PCIe Gen4 |
| Budget | 132 000 ₽ |

### Что сказал движок

```text
STRUCTURAL: FAIL
  GPU (348 мм) не влезает в корпус (макс 300 мм). Дефицит: 58 мм.
  Кулер (160 мм) не влезает в корпус (макс 160 мм). Дефицит: 5 мм.

POWER: BLOCK
  БП 450W недостаточен. Full load 505W, нужно минимум 556W.
  GPU 320W требует ATX 3.0/3.1. Текущий БП: ATX 2.4.

THERMAL: WARN
  CPU 83.2 °C — близко к пределу.
  Thermal soak: корпус не отводит 410W при ёмкости 300W.
  Прогноз: +5.5 °C при sustained нагрузке.

ACOUSTIC: WARN
  Класс шума A4 выше ограничения moderate (макс A3).

MVS: BLOCK
  X99: PCIe Gen4 при требовании тира Gen5.
  X99: VRM basic_stable при требовании sweet_spot_stable.
  1 × M.2 при требовании ≥2.

BUDGET: BLOCK
  132 000 ₽ > 120 000 ₽ на 12 000 ₽.
```

Итог:

```json
{
  "validation_status": "FAIL",
  "action_required": "rollback",
  "failed_check_ids": [
    "STRUCTURAL: Компоненты физически несовместимы.",
    "POWER: BLOCK: БП 450W недостаточен. Full load: 505W, нужно минимум 556W.",
    "MVS: чипсет X99 поддерживает PCIe Gen4, тир требует Gen5.",
    "BUDGET: 132,000₽ превышает потолок 120,000₽ на 12,000₽."
  ]
}
```

### Что здесь важно

Движок не спорит с тем, что RTX 4090 — хорошая карта. Его профиль `halo_4k_path_tracing` действительно `optimal` для 4K. Проблема не в карте, а в **сборке вокруг неё**.

Это ровно тот класс ошибок, который языковая модель допускает чаще всего: каждый компонент по отдельности «правильный», вместе — не собирается.

## 3. Чему учат примеры

| Наблюдение | Следствие |
|---|---|
| Валидная сборка получает `PASS_WITH_WARNINGS` | Вердикт не бинарный, оговорки сохраняются |
| Предупреждение по PCIe не исчезает | Движок не подгоняет вывод |
| GPU-профиль `optimal`, а сборка `FAIL` | Проверяется конфигурация, а не репутация компонента |
| X99 получает `BLOCK` по MVS | Правила консервативны и это видно |
| `cpu_vrm` и `gpu_pcie` отсутствуют во втором примере | Нет данных → проверка не выполняется, а не «проходит» |

Последний пункт — принципиальный. `SKIP` должен быть виден. Иначе «валидатор» превращается в генератор зелёных галочек.
